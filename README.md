# SignalLens — Customer Intelligence Lab

![SignalLens](assets/logo.svg)

A standalone portfolio demonstration by Blair Page. Interactive customer discovery, evidence classification, weighted prioritization and validation planning for a commercial facilities scenario. All example records and scores are synthetic. No original coursework files are included.

## Deploy
Upload the contents of this folder to a GitHub repository named SignalLens. Enable GitHub Pages from main / root. No dependencies, backend or API keys required.

## Features
Evidence filtering, normalized weighted ranking, CSV export, custom SVG identity and workflow diagrams, responsive layout and print styles.
